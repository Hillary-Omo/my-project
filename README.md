# Anime Personality Matcher

This is a small Python quiz I made that matches you with an anime character based on your personality. You answer a few questions and the program gives you a character that fits your answers best.

## How it works
Each answer is linked to a personality trait and adds points to it. At the end, the program checks which trait has the highest score and uses that to find your anime character.

## Project files
- `main.py` – the main program where the quiz runs.
- `questions.json` – contains the questions and answer options.
- `characters.csv` – contains the anime characters and their traits.
- `results.txt` – saves the results from completed quizzes.

## Running it
Open the project in PyCharm and run `main.py`. Answer the questions in the terminal to get your character match.

I made this project to practise using Python, especially functions, loops, if statements, reading files and saving results.
